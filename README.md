# hackit

A Python project.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

## Usage

```bash
python -m hackit
```

## Development

```bash
pytest          # run tests
ruff check .    # lint
ruff format .   # format
```
